# 🚌 Tamil Nadu Private OmniBus AI Chatbot

A professional AI-powered chatbot for searching Tamil Nadu private Omni buses using **FAISS**, **Sentence Transformers**, and **Gradio**.

---

https://colab.research.google.com/drive/12x7512A0Yoydvs-msGvGUQueNlpnZ7fl#scrollTo=GvctXETG9DFu



## 🚀 Features

- 🔍 Semantic bus search using FAISS
- 🤖 AI-powered natural language queries
- 🚌 Search by route, bus type, operator, fare, and amenities
- 💬 ChatGPT-style Gradio interface
- 📱 Responsive design
- ⚡ Fast vector search
- 🎯 Easy deployment to Hugging Face Spaces
