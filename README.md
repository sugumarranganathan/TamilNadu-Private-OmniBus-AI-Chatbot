# 🚌 Tamil Nadu Private Omni Bus AI Chatbot

An AI-powered chatbot for searching Tamil Nadu private omni buses using semantic search (FAISS), CSV filtering, and a modern ChatGPT-style interface.

## Features

- AI-powered natural language search
- Semantic search using FAISS
- Fast CSV filtering
- ChatGPT-style interface
- Modern responsive design
- Bus comparison
- Quick suggestions
- Rich bus cards

## Technology Stack

- Python
- Gradio
- FAISS
- Sentence Transformers
- Pandas
- NumPy

## Dataset

- bus_services.csv
- documents.pkl
- bus_index.faiss
